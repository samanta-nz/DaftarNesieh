# دفتر نسیه | DaftarNesieh

اپلیکیشن اندروید فارسی، راست‌به‌چپ و آفلاین برای حساب نسیه سوپرمارکت‌ها.

## قابلیت‌ها
- ساخت پروفایل مشتری: نام، نام خانوادگی، شماره تماس
- ثبت نسیه با شرح اجناس، مبلغ صحیح به تومان، زمان گوشی و نمایش شمسی
- ثبت دریافت وجه نقدی، کارتخوان یا کارت‌به‌کارت
- گردش حساب فردی همراه مانده پیش از بازه و مانده انتها
- داشبورد کل نسیه، کل پرداخت، وصول‌شده واقعی و مانده قابل وصول
- فیلتر همه، ۱، ۳، ۶، ۱۲ ماه اخیر و بازه شمسی سفارشی برای صورتحساب
- ساخت SMS خلاصه یا ریز صورتحساب، بازکردن در پیام‌رسان SMS با شماره مشتری
- تنظیم نام مغازه و عنوان شغل در راه‌اندازی اولیه و تیتر SMS
- بکاپ و بازیابی فایل JSON محلی و بدون رمزگذاری
- پنج پوسته رنگی و تشخیص روشن/تاریک گوشی

## بیلد APK
GitHub Actions روی هر Push به شاخه main اجرا شده و فایل `DaftarNesieh-debug-APK` را در Artifacts می‌سازد.
برای بیلد محلی در Codespaces:
```bash
gradle --no-daemon :app:assembleDebug
```
مسیر APK: `app/build/outputs/apk/debug/app-debug.apk`

## حریم خصوصی
اپ نیاز به اینترنت و دسترسی SEND_SMS ندارد. تمام اطلاعات مالی فقط داخل گوشی ذخیره می‌شود. ارسال SMS از طریق اپ پیامک دستگاه و با تأیید کاربر انجام می‌شود.
**هشدار:** خروجی JSON شامل اطلاعات مشتری‌ها به‌صورت متنی و رمزنگاری‌نشده است. از افشای آن جلوگیری کنید.

توجه: بیلد Debug امضای مخصوص توسعه دارد و برای انتشار رسمی به امضای Release نیاز است.
